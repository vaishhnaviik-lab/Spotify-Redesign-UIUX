# Spotify Redesign UI/UX 🎧
A Spotify mobile app UI redesign created using Figma.

## About the Project
This project focuses on redesigning Spotify's mobile interface with a clean and modern look, making music browsing and navigation visually appealing.

## Features
- Browse music and playlists
- Search songs and artists
- Explore the music library
- Modern and user-friendly interface

## Tools Used
- Figma
